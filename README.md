# airline-flight-price-analysis
Power BI dashboard analyzing airline ticket prices, travel classes, stops, routes, and booking lead times.

![Airline Flight Analysis Dashboard](dashboard.png)


📊 Key Insights

The airline flight analysis dashboard explores flight prices, travel duration, number of stops, and differences across airlines and routes.

- Flight Price Comparison: Flight prices can vary across airlines, travel classes, and source-destination routes.
- Travel Duration: Flight duration varies depending on the selected route and the number of stops.
- Impact of Stops: Comparing non-stop and connecting flights helps explore differences in travel time and ticket prices.
- Airline Analysis: Comparing airlines helps identify differences in average ticket prices and travel duration.
- Route Analysis: Comparing source and destination cities helps explore route-level differences in flight costs.
- Travel Planning: The dashboard allows users to filter flight information and compare available options based on price, duration, and stops.

💡 Project Conclusion

This project demonstrates how Power BI can be used to transform raw airline flight data into an interactive dashboard. By combining data cleaning, visualization, and analytical measures, the dashboard helps users explore flight prices, compare airlines, and understand travel patterns.

The project also demonstrates practical skills in data preparation, data visualization, and business intelligence reporting.
